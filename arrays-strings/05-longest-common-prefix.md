# Longest Common Prefix

## Problem: Longest Common Prefix (Easy)

**Link:** https://leetcode.com/problems/longest-common-prefix/

### Approach

Compare characters of the first string with the next strings one by one and stop when the prefix no longer matches.

### Complexity

- Time: O(n * m)
- Space: O(1) extra space

### Notes

This solution finds the common prefix across all strings in the array.
