# Valid Parentheses

## Problem: Valid Parentheses (Easy)

**Link:** https://leetcode.com/problems/valid-parentheses/

### Approach

Use a stack to keep track of opening brackets. When a closing bracket appears, it must match the most recent opening bracket.

### Complexity

- Time: O(n)
- Space: O(n)

### Notes

The stack ensures proper bracket matching and handles nested pairs correctly.
